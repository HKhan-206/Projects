# Strawberry Millions Milkshake – animated promo (1080 × 1920)

| Folder / file | What it is |
|---|---|
| `higgsfield/` | Generated assets: 3 stills (GPT Image 2.6) and 2 clips (Kling v3.0 pro) |
| `layers/` | Separate layers: cut-out strawberry pieces, plus keyed frame sequences of the clips (`./make-layers.sh` rebuilds those) |
| `source/` | The milkshake photograph (used unaltered) and the reference frame |
| `promo.config.js` | Timing, positions, sizes and title text – edit this |
| `index.html`, `composite.js` | The compositor (open `index.html` to play it) |
| `output/` | Rendered MP4s |

The milkshake photo is only positioned, sized and tilted – never retouched.
